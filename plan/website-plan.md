## 3. Design System Brief

### Brand extraction (from kovele-brand skill)
- **Primary:** #333D9B (Kovele Blue) — buttons, links, headings, nav
- **Secondary:** #282F7A (Deep Blue) — hover states, secondary elements
- **Accent:** #E8722A (Hi-Vis Orange) — primary CTAs, phone number highlights
- **Gold:** #FFD700 — star ratings only, very rare
- **Muted:** #ECEEFF — light section backgrounds
- **Surface dark:** #1A1E4A — footer, hero overlays
- **Heading font:** DM Sans (700 for H1-H2, 600 for H3-H4)
- **Body font:** Inter (400 body, 500 labels)
- **Logo:** Cartoon plumber character with "Kovele Plumbing" text

### Design direction
Trust-first trades site for a father-son Melbourne plumbing team. Clean, blue-dominant
palette with white space. The orange hi-vis accent draws the eye to CTAs and the phone
number. The site should feel like a modern, professional trades business — not a corporate
plumbing franchise, but not a cheap one-pager either. Think of it as "the best plumber
website in Melbourne" — the kind of site that makes competitors look dated.

Melbourne terrace houses and inner-north streetscapes set the imagery context. Every page
should feel local, warm, and trustworthy. The 247 reviews and 40 years of experience are
the two biggest trust signals — make them impossible to miss.

## 4. Tech Recommendation

| Factor | Decision | Reasoning |
|--------|----------|-----------|
| Framework | **Vite + React 19** | Fast build, SPA with pre-rendering for SEO. 31 pages is manageable with static generation. No server needed. |
| CMS | **No CMS** (Phase 1) | Steve won't update content himself. Roadmap manages updates. CMS adds complexity with no benefit. Blog posts are static markdown in Phase 1. Sanity can be added later if needed. |
| Hosting | **Vercel** | Default Roadmap stack. Free tier covers this traffic level. |
| Styling | **Tailwind v4 + CSS custom properties** | Component library already uses this. Brand tokens via brand.css. |
| Components | **Roadmap Component Library** | 42 standalone components, trades vertical, CSS variable theming. |
| SEO | **react-helmet-async + pre-rendering** | Meta tags, structured data, sitemap.xml, robots.txt. Pre-render all 31 pages for Google. |
| Forms | **Formspree or Basin** | Simple form backend for quote requests. No backend needed. |
| Analytics | **Google Analytics 4 + Search Console** | Standard tracking. Set up conversion events for calls and form submissions. |
| Images | **AI-generated + optimised** | Nano Banana for hero/service imagery. Served as WebP, lazy loaded. |
